📘 Panduan penggunaan

1. Login dan koneksi Google Drive

Klik “Hubungkan Google”, pilih akun Google yang benar, lalu izinkan akses Drive. Setelah login, status koneksi muncul di bagian atas.

2. Upload banyak video

Pilih file apa saja atau folder, klik “Tambahkan ke antrean”, lalu “Mulai antrean”. Upload berjalan satu per satu agar penggunaan koneksi lebih stabil. Jeda, lanjutkan, atau batalkan dari kontrol pada kartu upload.

3. Jeda dan pulihkan upload

Jeda menghentikan pengiriman bagian berikutnya. Riwayat dan data sementara disimpan di folder data aplikasi. Setelah halaman dimuat ulang, upload yang belum selesai bisa dicoba dilanjutkan dari daftar riwayat jika file sumber dipilih kembali. File sumber tidak disimpan permanen di browser.

4. Folder, pencarian, preview, dan pengelolaan

Buka folder dengan tombol “Buka”. Gunakan pencarian dan filter untuk menemukan file. Klik “Preview” untuk memutar video, “Rename” untuk mengganti nama, dan “Hapus” untuk menghapus file dari Google Drive.

5. Menutup dan membuka kembali aplikasi

Jangan tutup jendela terminal selama server dibutuhkan. Buka kembali aplikasi dengan menjalankan start.bat. Setelah server dimulai ulang, login Google mungkin perlu diulang karena sesi web disimpan oleh server.

Catatan: fitur upload besar bergantung pada koneksi internet dan kuota Google Drive. Upload yang sudah sampai tahap pengiriman ke Google Drive dapat perlu dicoba ulang jika Google menolak transfer akhir.
